# More practice like this (for after, or when you want extra)

All free. All links checked 2026-11-15.

## Exercise sets in the same style (numbered, easy → hard)
| Set | Topic | Notes |
|---|---|---|
| [rougier/numpy-100](https://github.com/rougier/numpy-100) | NumPy | The original. Good extra practice after your Day 26 |
| [Kyubyong/numpy_exercises](https://github.com/Kyubyong/numpy_exercises) | NumPy | Organised by topic, like the NumPy docs |
| [ajcr/100-pandas-puzzles](https://github.com/ajcr/100-pandas-puzzles) | pandas | You already did ~20. Finish it after Day 30 |
| [guipsamora/pandas_exercises](https://github.com/guipsamora/pandas_exercises) | pandas | Real datasets (Chipotle orders, Euro 2012, etc.) |
| [Kaggle Learn: Pandas](https://www.kaggle.com/learn/pandas) | pandas | Short lessons + exercises that check your answer for you |
| [Kaggle Learn: Intro to ML](https://www.kaggle.com/learn/intro-to-machine-learning) and Intermediate ML | scikit-learn | Very beginner-friendly, ends with a real competition |
| [INRIA scikit-learn MOOC](https://inria.github.io/scikit-learn-mooc/) | scikit-learn | Free course **by the people who make scikit-learn**. Excellent after Day 33 |

## Books (free online)
| Book | Why |
|---|---|
| [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/) (Jake VanderPlas) | NumPy, pandas, matplotlib, sklearn: the same topics as this folder, explained deeper |
| [Hands-On Machine Learning, code notebooks](https://github.com/ageron/handson-ml3) (Aurélien Géron) | The best ML book. The notebooks are free; the book is worth buying later |
